# Installation

Use the package configuration and deployment manifests at the selected source
revision. Configure credentials in private environment files. Preserve encryption
keys, account identity and provider authentication when restoring existing state.
Check provider readiness and message delivery before enabling normal dispatch.

For a host transfer, stop writers and take fresh database and asset backups.
Never start the same paired identity on independent hosts simultaneously. Keep
host paths, account inventories and operational verification records private.
